# GLSOOBE
The Offical Windows Glass Out Of Box Experience (OOBE)

Built using WPF and C#, this OOBE is designed to replicate Windows Longhorn Build 4001 OOBE, which was also included in the files of all future Longhorn builds, except for Builds 4002, 4084, x64 compiles and 4093

## System requirements (target)
- Windows XP SP2
- .NET Framework 3.5
- 400MHz Pentium Processor or equivalent
- 128MB RAM

## Build prequisites
- Visual Studio 2019 or newer
- .NET Framework 3.5 and 2.0 enabled
- .NET Desktop Development workload
- Windows 7 SP1 or newer (VS2019 and VS2022 17.6 LTSC only)
